# AEGIS REACH // NATIVE TERRAIN HANDOFF

## Why this pass exists

Relayfall's story objects are beginning to work, but the current landform still reads as a flat construction plane with props placed on top. That is the wrong foundation for the game we want.

GameGuru MAX already has a real Terrain Generator / Terrain Editing workflow. From this point forward, terrain should be authored as terrain whenever possible, with meshes reserved for architecture, cliff overhangs, deep caves, alien structures, and deliberate hard-surface set pieces.

The goal is not random mountains. The goal is a legible alien landscape that creates encounter rhythm, discovery, and environmental history.

## New native source

Run:

```bat
python tools\vesper_terrain_source.py
```

This generates:

```text
Aegis Reach\Design\terrain-source\vesper_relayfall_height_16bit.png
Aegis Reach\Design\terrain-source\vesper_relayfall_basecolor.png
Aegis Reach\Design\terrain-source\vesper_relayfall_terrain.json
```

Use the 16-bit image as the Terrain Generator heightmap source. The base-color image is an art-direction/reference map; it can guide terrain painting even if MAX does not use it directly in the same import step.

A 1024 x 1024 source is generated by default. For a higher-detail source:

```bat
python tools\vesper_terrain_source.py --size 2048
```

## Intended landform sequence

The height source is composed around large readable forms:

1. **Relayfall mesa** — the fortress occupies an older geologic rise that was later flattened by military construction.
2. **South threshold** — a broad slope leaves the fortress instead of a slab edge.
3. **Evaporite basin** — the old brine sea floor; pale, open, and dangerous to cross without using terrain.
4. **Dried brine channel** — a lower sinuous cut that divides movement and records old water flow.
5. **West basalt bench** — broad elevated flank / firing position.
6. **East basalt bench** — opposing high ground and route toward stranger geology.
7. **Outer shelf** — quieter, more exposed land that opens the horizon.
8. **East tidal fracture** — a deeper cut that can later become the approach to Undertide.
9. **North escarpment** — frames the installation and prevents the world from reading as an infinite tabletop.
10. **Distant rim** — broad raised terrain at the playable horizon.

## Indoor / outdoor composition

The desired mission rhythm is not "outdoor level, then indoor level."

It should repeatedly alternate between enclosure and release:

**open shelf -> breach -> fortified service interior -> relay courtyard -> maintenance interior -> wide basalt vista -> AEGIS structure -> exterior return route**

Each transition should change at least three things:

- sightline length;
- combat weapon preference;
- ambient sound / music;
- lighting temperature;
- route complexity;
- enemy composition;
- emotional tone.

The player should feel the relief of stepping outside after compression, and the tension of entering an unknown structure after a huge exterior vista.

## MAX editor workflow

1. Pull the current `main` and run the terrain source generator.
2. Open Relayfall in GameGuru MAX.
3. Use the Terrain Generator / Terrain Editing workflow and import the generated 16-bit heightmap.
4. Start with a moderate vertical range (the manifest suggests roughly 180 m) and adjust until the fortress plateau, basin, ridges, and distant rim feel correctly scaled against the existing architecture.
5. Terrain-paint the old sea floor pale/evaporitic and high shelves dark basalt. Preserve one consistent old waterline rule.
6. Sculpt locally after import. The heightmap is a composition scaffold, not sacred data.
7. Save Relayfall in MAX.
8. Bring the editor-authored `.fpm` back into Git with:

```bat
python tools\sync_max_map.py pull --dry-run
python tools\sync_max_map.py pull
```

The pull tool backs up the previous repo `.fpm` first.

## Terrain rules

### Terrain is gameplay

A ridge that does not affect movement, line of sight, or orientation probably does not need collision.

Use the real terrain for:

- broad slopes;
- basins;
- terraces;
- channels;
- ravines;
- distant ridges;
- combat elevation.

Use meshes for:

- hard alien geometry;
- architectural cliffs / retaining walls;
- overhangs terrain cannot represent;
- tunnels and true caves;
- bridges and causeways;
- localized rock formations that need precise silhouette.

### Preserve readable routes

Never turn Vesper into a noise field of tiny hills. At combat distance the player should be able to identify:

- the dangerous open crossing;
- the safe-but-long flank;
- the high ground;
- the fallback route;
- the destination landmark.

### The landscape remembers the sea

Low land is pale and mineral-loaded. High basalt stays darker. Historic structures crossing the old waterline inherit the same mineral boundary.

### Geology creates architecture

Civilian survey crews bridge fractures and use geothermal zones. AEGIS construction ignores or armors over older routes. Iron Wardens occupy both.

If a building could be moved 500 meters in any direction without changing its story or gameplay, its placement probably is not finished.

## Next production goal

Once the native terrain is saved into Relayfall, the next environment pass should stop expanding the old procedural floor and instead:

- conform encounter objects to terrain elevation;
- replace temporary slab edges with terrain slopes / cliff treatments;
- cut two clear exterior-to-interior transitions through the fortress;
- use installed DLC for believable doors, machinery, catwalks, signage, utility rooms, and occupation clutter;
- reserve original custom assets for Vesper geology, Meridian history, and the Choir so the game's identity does not become a DLC collage.
