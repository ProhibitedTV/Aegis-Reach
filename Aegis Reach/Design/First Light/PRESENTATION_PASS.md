# FIRST LIGHT // Presentation Pass

This pass improves how the existing mission communicates itself without changing the environment composition being evaluated in the current native MAX playtest.

Goals:

- reduce the debug-overlay feeling of the HUD;
- keep navigation useful without making floating text responsible for level readability;
- make zone arrivals short, contextual and non-repetitive;
- drive the existing semantic music controller from real combat contact;
- distinguish ordinary combat, AEGIS interference combat and the final extraction holdout;
- preserve all objective coordinates, encounter positions and environment geometry.

Native environment feedback from the current playtest should therefore remain directly comparable after this pass.
