# FIRST LIGHT // Installed MAX Asset Palette

This file records licensed GameGuru MAX assets available in the developer's local installation that are appropriate for First Light. These are local dependencies only: reference their entitybank paths from build tools, but never copy proprietary DLC payloads into Git.

## Environment rule

Use this order of preference for human-built spaces:

1. Native MAX terrain for grounded walking surfaces and large-scale landform.
2. Installed modular sci-fi / cyberpunk / construction assets for finished human architecture and infrastructure.
3. Industrial and military assets for functional dressing and occupation history.
4. Small bespoke generated meshes only for unique silhouettes or shapes the installed kits cannot provide.

Generated primitive boxes are not a substitute for available modular kit pieces.

## Military occupation palette

Use Booster Pack Military Pack assets for Iron Warden retrofit only: barriers, containers, Hesco, sandbags, lockers, gun racks, generators and cots. Meridian civilian areas should not read as military camps until the occupation layer is visible.

## Visual guardrails

- Prefer one strong modular asset cluster to six repeated generated frames.
- Do not put cyberpunk neon everywhere. Blue/cyan trims are primarily AEGIS and selected technical infrastructure.
- Construction assets should look like ongoing work, survey operations or emergency repair—not a contemporary Earth construction site dumped wholesale onto Vesper.
- Test scale and orientation in native MAX screenshots. If an asset reads wrong, remove or rescale it rather than compensating with more clutter.
- Never create a coplanar modular floor over native terrain.
